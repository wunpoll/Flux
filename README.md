# 📈 FLUX Analytics - Интеллектуальная торговая платформа

**FLUX Analytics** — это кроссплатформенное мобильное приложение для трейдеров и инвесторов, сочетающее в себе реальные рыночные данные, продвинутую техническую аналитику и искусственный интеллект. Приложение имитирует функционал биржевого терминала с возможностью спотовой торговли, управления портфелем и получения инсайтов от AI.

Стиль проекта: Минимализм, премиальный дизайн ("Silicon Valley vibe"), полная адаптация под Темную/Светлую тему.

## 🎯 Ключевые возможности

Проект реализует сложную бизнес-логику с разделением ролей и использованием облачных вычислений.

### 🤖 AI-Аналитик
- **Контекстный анализ:** Чат с ИИ (Google Gemini 1.5 Flash), который "видит" текущий график, индикаторы (RSI, SMA) и цену актива.
- **Безопасная архитектура:** Запросы к ИИ проходят через **Firebase Cloud Functions**, что исключает хранение API-ключей на клиенте.

### 📊 Рынок и Графики
- **Real-time котировки:** Подключение к **Binance API** (Криптовалюты) и **MOEX ISS API** (Акции РФ).
- **Продвинутые графики:** Свечные графики (Candlesticks) с таймфреймами от 1 минуты до 1 недели.
- **Технический анализ:** Автоматический расчет индикаторов **RSI** (Relative Strength Index), **SMA** (Simple Moving Average) и **Волатильности** на клиенте.

### 💼 Торговля и Портфель
- **Симуляция Торговли:** Покупка и продажа активов с реальным списанием USD и начислением лотов.
- **Умный портфель:** Расчет **Net Worth** (Общего капитала) и **Unrealized PnL** (Нереализованной прибыли) на основе средней цены покупки (Weighted Average Price).
- **Поддержка дробных лотов:** Возможность купить 0.0005 BTC.

### 🔔 Уведомления и Алерты
- **Мониторинг цен:** Пользователь может задать целевую цену.
- **Фоновая проверка:** Система Polling-а проверяет цены каждые 30 секунд и уведомляет пользователя (Red Dot индикация) при срабатывании условий.

### 👥 Система Ролей
- **Guest:** Базовый доступ, лимит на 5 алертов.
- **PRO:** Безлимитные алерты, доступ к проф. индикаторам (MACD).
- **Admin:** Доступ к **Admin Console** (управление пользователями, системная аналитика, статус серверов).

## 🏛️ Архитектура и ключевые решения

Проект построен с упором на **безопасность** и **чистую математику**.

### 1. Безопасность ИИ (Enterprise Level)
Вместо хранения ключей Vertex AI внутри приложения (что небезопасно), реализована схема:
`Flutter Client` -> `Cloud Functions (Node.js)` -> `Vertex AI`.
Это скрывает логику промптов и ключи от конечного пользователя.

### 2. Математическое ядро (`AnalysisService`)
Индикаторы не запрашиваются с API, а рассчитываются математически на устройстве на основе массива свечей:
- **RSI:** Сглаженный алгоритм (Smoothed Moving Average).
- **Volatility:** Расчет стандартного отклонения (Standard Deviation) за период.
- **Логика PnL:** Учет средней цены входа при усреднении позиций.

### 3. Отказоустойчивость и UX
- **Safe Networking:** Обработка тайм-аутов и ошибок сети. В Админ-панели реализована диагностика соединения (Online/Offline/Cached).
- **Self-Healing Auth:** Механизм восстановления записи пользователя в Firestore, если она была случайно удалена, но Auth-сессия активна.
- **Оптимизация MOEX:** Обход кэширования API биржи через timestamp-параметры.

### 4. Схема базы данных (Cloud Firestore)

- **`users`**:
    - `role`: 'guest' | 'pro' | 'admin'
    - `balance`: double (USD)
    - `favorites`: array (список тикеров)
- **`users/{uid}/portfolio`**:
    - `amount`: Количество актива
    - `avgPrice`: Средняя цена покупки (для расчета PnL)
- **`users/{uid}/alerts`**:
    - `ticker`, `targetPrice`, `condition` (>, <), `status` (active/triggered), `isRead`.

## ✅ Тестирование

В проекте реализованы оба типа тестов для подтверждения надежности:
1.  **Unit Tests:** Покрытие математического ядра (`AnalysisService`) — проверка формул SMA, RSI и граничных значений.
2.  **Integration Tests:** Тестирование флоу авторизации (`LoginScreen`) с использованием **Mock-сервисов** и **Dependency Injection** (подмена реального Firebase на заглушки).

## 🌍 Локализация (i18n)

Реализована собственная легковесная система локализации (`ValueNotifier` + `AppStrings`), позволяющая переключать язык (RU/EN) **на лету** без перезагрузки приложения. Поддерживается перевод всех экранов, включая ошибки и системные сообщения.

## 🚀 Как запустить

1.  **Flutter:**
    ```bash
    flutter pub get
    flutter run
    ```
2.  **Cloud Functions (Backend):**
    В папке `functions/` (требуется Node.js):
    ```bash
    firebase deploy --only functions
    ```
    *Примечание: Для работы AI требуется проект Firebase с планом Blaze (Pay-as-you-go).*
